# CivicCare — Civic Complaint Portal Prototype

Open `index.html` in any modern browser.

Prototype includes:
- Citizen dashboard
- Submit complaint form
- Complaint tracking/search
- Complaint details and progress timeline
- Admin dashboard
- Admin complaint status updates
- Responsive laptop/mobile layout
- Sample municipal complaint data

This is a front-end prototype for a Software Engineering project; data is stored only in browser memory and is not connected to a real backend/database.
